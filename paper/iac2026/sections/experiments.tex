\section{Experimental Protocol}
% Dataset / split / annotation / baselines / metrics / hardware / proxy + Jetson:
% see EXPERIMENT_PROTOCOL.md (authoritative). Do not expand textbook metric formulas here.
Evaluation uses NASA Mars rover imagery under the splits and labeling rules documented in
the experiment protocol.
Baselines include PaDiM/PatchCore-style anomaly detection~\citep{defard2020padim,roth2022patchcore}.
Reported metrics are named (AUROC, AUPRC, F1, FPS) without formula derivations.
Proxy ablations for shadow/FP gates and size--distance policy use class labels, masks, and
OFF-run pseudo-ground-truth; they are not human bounding-box ground truth.
A Jetson / edge-hardware protocol is defined but not yet executed (support: planned).
