\subsection{Historical accepted-abstract track}
The accepted IAC abstract reports AUROC~$0.894$, AUPRC~$0.847$, F1~$0.823$, baseline
AUROC~$0.856$, and $28.1$\,FPS at $256\times256$ for a lightweight core.
Table~\ref{tab:accepted-abstract} restates those values; lightweight FPS is reported only
there.

\subsection{Current reproducible evaluation (\texttt{independent\_eval\_v1})}
Protocol definitions, annotation rules, and frozen execution settings are version-controlled
with the implementation, including image-score aggregation, preprocessing profile, and
checkpoint hashes.
The primary image score is \texttt{max\_valid\_candidate\_after\_masks}.
The held-out test partition was not opened: no test inference, no test metric, and no
threshold retune on held-out images.
Numeric supplementary results below use the human-reviewed annotation version only.
The qualitative example in Figure~\ref{fig:qualitative} uses one deterministically selected
non-test image from the same manifest under the frozen image-score path.
Figure~\ref{fig:close-far} adds one close-range and one distant-scene illustration from a
fixed author-provided pool; it is not a range-conditioned performance study.

\subsection{Supplementary human-reviewed annotation (\texttt{independent\_eval\_v1\_1})}
\texttt{independent\_eval\_v1\_1} records a model-blind repeat-author review of all 360
included images under the same annotation guide.
The original \texttt{independent\_eval\_v1} manifest remains immutable.
Split assignments are unchanged; the test split remains unopened (human viewing only;
no ARTPS inference).
Scores were remapped onto the reviewed labels with no tuning and no inference rerun.
This is not an independent second annotation.

\subsection{Dataset and annotation semantics}
One homogeneous Curiosity Mastcam-oriented image domain was selected from inventory metadata
without model-score inspection.
The frozen supplementary benchmark comprises $360$ included images with fixed split
assignments of $252$ train / $54$ validation / $54$ test.
All $360$ images received a repeat-author model-blind review; this is not independent double
annotation.
Test images could be viewed for annotation, but no ARTPS inference was performed on the
held-out test split.
A positive label denotes at least one real surface object or region that is visually distinct
from its surroundings and scientifically worth follow-up under the annotation guide.
A negative label denotes no distinct science-interest target under that guide.
Rover hardware, border artefacts, telemetry overlays, compression or noise artefacts, a
shadow boundary alone, or an exposure/specular artefact alone do not count as positive.
These labels are not claimed to be equivalent to the historical accepted-abstract ground truth.

\subsection{Baseline scope}
The PaDiM/PatchCore baseline AUROC~$0.856$ belongs to the historical accepted-IAC track~\citep{defard2020padim,roth2022patchcore}.
No current-protocol PaDiM/PatchCore comparison is claimed for \texttt{independent\_eval\_v1\_1}.
PaDiM and PatchCore remain separate baselines and are not active components of the current
frozen score.

\subsection{Metrics}
Historical reported metrics are AUROC, AUPRC, F1, the historical baseline AUROC, and
lightweight-core FPS.
For the supplementary \texttt{independent\_eval\_v1\_1} validation, AUROC is the principal
ranking-oriented metric and AP is a secondary metric reported with prevalence context.
Threshold-dependent F1 is not treated as a performance measure on that track.

\subsection{Reproducibility and evaluation integrity}
The evaluation uses the frozen configuration, checkpoint hashes, and image-score definition
stated above.
There was no test inference, no test metric, and no threshold retuning on held-out images.
Runs are aborted when required inputs or frozen protocol conditions are incomplete.

\subsection{Hardware scope}
The reported $28.1$\,FPS value is a historical lightweight-core workstation measurement; it
excludes learned DPT and autoencoder inference.
The present study does not report full-pipeline edge-hardware or Jetson timing.
No flight qualification is claimed.
