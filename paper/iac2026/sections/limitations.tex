\section{Limitations}
\label{sec:limitations}
Monocular depth in ARTPS is \emph{relative}, not metric: near/far ordering does not yield
metres, physical object size, or calibrated 3D reconstruction~\citep{ranftl2021dpt}.

The qualitative figures are non-test illustrations and do not represent field diversity
or a controlled near/far study.
The human-reviewed performance analysis is based on the 54-image validation partition; the
reserved test partition was not used for ARTPS inference or performance reporting.
The human-reviewed set is a repeat-author review, not an independent second annotation.
The human-reviewed set contains only $20$ negatives among $360$ images ($8$ validation,
$2$ test).
The present human-reviewed validation subset contains only eight negative
examples, making operating-threshold calibration unstable.
The small number of negative validation examples limits both operating-threshold calibration
and the precision of the AUROC estimate.
The image-level score does not include curiosity ranking, diversity
penalty, or the Priority Buffer.
The training-set lineage of the fixed checkpoints was not independently cross-checked against
the human-reviewed corpus; the human-reviewed analysis is therefore treated as an additional
validation study rather than an external benchmark.
No embedded/Jetson or full-pipeline timing result is added here.

ARTPS is a safety-aware, flight-readiness-oriented software architecture.
It is not flight-qualified avionics, not mission-certified, and does not assert
universal safety guarantees.
Operational envelopes, independent V\&V, and mission-specific safety evidence remain
out of scope.
