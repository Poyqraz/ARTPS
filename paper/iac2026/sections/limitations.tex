\section{Limitations}
\label{sec:limitations}
Monocular depth in ARTPS is \emph{relative}, not metric: near/far ordering does not yield
metres, physical object size, or calibrated 3D reconstruction~\citep{ranftl2021dpt}.

See Table~\ref{tab:eval-tracks} for the historical versus supplementary evaluation tracks.
The qualitative processing example is a single non-test illustration and does not represent
field diversity.
The \texttt{independent\_eval\_v1} held-out test partition was not opened.
The supplementary \texttt{independent\_eval\_v1\_1} audit is a repeat-author review, not an
independent second annotation.
The human-reviewed set contains only $20$ negatives among $360$ images ($8$ validation,
$2$ test); it is therefore unsuitable for a strong independent final-test classification
claim.
The present human-reviewed validation subset contains only eight negative
examples, making operating-threshold calibration unstable.
The frozen image-level score does not include curiosity ranking, diversity
penalty, or the Priority Buffer.
Frozen checkpoint training provenance is unverified relative to this dataset.
No final test was opened and no embedded/Jetson result is added here.

Proxy analyses are preliminary and non-headline; they do not replace human-annotated
localization benchmarks where those are required.

ARTPS is a safety-aware, flight-readiness-oriented software architecture.
It is not flight-qualified avionics, not mission-certified, and does not assert
universal safety guarantees.
Operational envelopes, independent V\&V, and mission-specific safety evidence remain
out of scope for this manuscript draft.
