\subsection{Current frozen evaluation protocol}
The \texttt{independent\_eval\_v1} heuristic-label track remains a separate frozen protocol.
The held-out test set remains unopened, so the current protocol is reported as validation-only.
Numeric supplementary validation below uses the human-reviewed annotation version only.

\subsection{Supplementary Human-Reviewed Evaluation}
Table~\ref{tab:indep-v11} reports a validation-only audit under
\texttt{independent\_eval\_v1\_1}.
Frozen ARTPS image scores (FP32) use the frozen image-level score; labels were remapped with
no tuning and no inference rerun.
Curiosity ranking, diversity penalty, and the Priority Buffer were not applied on these
scores.
AUROC is the principal ranking-oriented metric for this supplementary validation.

The predeclared F1-based validation threshold selection collapsed to an
all-positive operating point.
Consequently, threshold-dependent classification metrics are not treated as
performance measures in this supplementary evaluation; AUROC is used as the
principal ranking-oriented metric.

\subsection{Qualitative processing example}
Fig.~\ref{fig:qualitative} is a single non-test illustration of RGB input, the
post-suppression combined anomaly map, relative depth, and candidate-support overlay under the
frozen image-score path.
Fig.~\ref{fig:cue-decomp} decomposes that same frozen fusion path into reconstruction,
relative-depth-edge, and texture cues plus the pre-suppression fused map; it is not a new
detection metric.
In addition to that single-scene example and cue decomposition, Fig.~\ref{fig:close-far}
shows one close-range and one distant-scene illustration selected from a fixed author-provided
pool, to show how the current frozen pipeline behaves under different apparent object-scale
contexts.
These examples are qualitative and are not a controlled near/far benchmark.
None of these figures enters Table~\ref{tab:accepted-abstract} or Table~\ref{tab:indep-v11},
opens the test split, or adds an AUROC, AUPRC, F1, or throughput number.
